Native rows (XOffset's own delta) compare with the rival's application-level case. Rivals in their no-check mode where they have one (信任档). XOffset: 信任档 xoffset_trusted (XReceiver admit, #228) in the application-level rows and class 1; native and D3 rows: 完整校验 (delta trust tier comes with P2); xoffset with the full check is report only. All messages are compressed (zstd-3 per message) but compression is not in the compared time (susu 00:59Z 11-05): main columns = server *.send, bytes after zstd, client receive + merge.
