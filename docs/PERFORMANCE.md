# 性能数字（3.6.0）

本页记录每个正式版在 Mac 检查点上测得的数字、测法和局限。所有数字来自同一台
Apple M4 和同一个游戏服务器负载（SLG），不要拿来推断别的机器、别的负载或别的适配写法。
Linux、Windows 上没有正式计时结论，手机上只有一台 iPhone 的同机对比（第 4 节）；云端的指令数只用来拦截回退
（[PERF_GATE.md](PERF_GATE.md)），不作为快慢的证据。3.5.0 起另有一组云端 x86-64 的计时（第 6 节），
机器不安静；3.5.0 只报，3.6.0 起按点估计设门槛（第 6a 节，[RELEASING.md](RELEASING.md) 第 2a 节）。

## 1. 测法

| 项 | 设定 |
| --- | --- |
| 机器 | Mac mini M4，macOS 26.3，P2996 Clang `d77eff1`，libc++，Release |
| 负载 | `bench/slg`（冻结树，见其 `MANIFEST`）：A 战斗服往返、B 跨服迁移、C 分区快照、D 战报只读；M 规模，`SLG_REUSE=1`（协议 c，缓冲区复用） |
| 对手 | zpp_bits、cista、cereal、protobuf、FlatBuffers，六家在同一个进程里轮流跑，每个周期都核对六家结果一致 |
| 样本 | 12 个进程，每个进程 41 个周期；进程之间等安静条件（屏幕黑，WindowServer < 20%，远程 < 5%，持续 60 秒） |
| 统计 | 每格是 XOffset ÷ 对手的几何均值和进程级单侧 95% 上界（Bonferroni k=20，df=11）。越小越好，上界 ≤ 1.0 才算「不慢于」 |
| 重定位税（G9） | `bench/reloc`：XOffset 容器 ÷ 同功能的 std 容器（set 对 `flat_set`），8 次 ABBA，k=19，上界 ≤ 1.05 算满足 |

判定和原始数据在 project files 的 `perf-gate/mac/<日期>-<批次>/VERDICT.md`，每节下面写了是哪一批。

## 7. 局限

- 正式计时只有一台 M4。别的 arm64 核（存储转发、分支预测不同）上的快慢关系可能不一样；x86-64 只有第 6 节那组
  不安静的云端数字；
  云端 GCC 16 + libstdc++ 的重定位税数字和 Mac 差得很多（libstdc++ 的 `flat_set`/`flat_map`
  与 libc++ 不同），只用来定位。
- SLG 是一个负载、一套适配写法（`bench/slg` 里的各家适配），换一种写法数字会变。
- 只测了缓冲区复用（协议 c）；每条消息新建缓冲区的数字没有作为结论。
- 上界针对「XOffset 不慢于对手」这一侧；比值远小于 1 的格子只说明在这个负载上领先，
  不说明领先的倍数在别处成立。
