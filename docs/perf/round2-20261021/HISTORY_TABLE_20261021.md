## 2. 没有同机同口径数据的历史版本

下面三行都**不是**现行协议（完整校验、独立拥有输出、demo 九阶段）下的测量，数字来自云端此前的代码与历史结果分析，按原样标注，不和上表直接比较。

| 版本 | 读取 / 修改 / 输出 / 加载 | 来源与性质 | 为什么不能放进上表 |
| --- | --- | --- | --- |
| v1（deprecated/experiment，CppCon 2024 原型） | 留空 | 历史基准结果（旧机） | 发送返回内部缓冲区引用、接收直接接管缓冲区，不复制也不校验；计时循环第一次就把缓冲区移走，之后 0.053 ms 的收发数字测的是空 vector 的移动；读写表中 FlatBuffers、Cap'n Proto、MessagePack 三行完全相同（68.0446），跑的是同一段 std 容器代码。没有可比数字 |
| v2（main / release/v2.0-* / next_practical，Boost.Interprocess） | 只有相对值：原版 next_cpp26 比 v2 快 1.07–1.61 倍；加载是 v2 的 0.57 倍 | 云端分析（他机，非本协议） | 接收接管缓冲区、不校验；加载更快正是因为不做校验 |
| 原版 next_cpp26（W9a 之前，alpha 7539433 一系） | 只有微基准：现行版本保存快约 3.5–4 倍、扩容快约 2.4 倍 | M3 Pro 上的存储微基准（他机）；累计倍数是几次单独运行相乘的**推断** | 没有 demo 口径的测量。指针解析与 W9a 是同一段 `origin + delta` 代码 |

## 3. 说明

- 本表没有为历史版本新做任何测量。为准备历史测量，曾在 Mac 上为 alpha 7539433 编出对比工具并跑了两次功能校验（S、M 通过），按要求停止，未做任何计时，相关数字不入表。
- 第 1 节结论只适用于本机与 alpha 时期对比工具元数据（与 final-v4 相比 9 个文件不同，对 cista 两项影响最大）。
