# C14 迭代阶段验证矩阵

本文件是新迭代的验证约束，不是已经执行或通过的记录。用户已选择在当前机器恢复；旧窗口、冻结交付及失败证据保持原状。根统筹只负责阶段授权、调度和验收；验证子会话是唯一实际重负载执行者，构建、SAN、业务和计时均走原全局共享租约。其他子会话/agent 的评审或代码产物不能自动取得执行权。

## 固定验收口径与状态

- 源码基线为已验收的 C14/final-v4 十四文件闭包；交接提交为 `1904b9c71230026ac6f2d58f919a9ab76447d264`。主头 SHA256 为 `66818de49b18fe85ab8049c9f9ad299bbebbb214eb3fceee0a665fe65f4275c3`。C14 是交付标签，不是 C++14。
- 正式结果为 XOffset 除以同批每个固定竞品：读取合计上界 ≤1.05、修改上界 ≤1.05、原 demo 完整独立拥有输出上界 ≤0.20；四竞品为 cista、FlatBuffers、Cap'n Proto、cereal。重载完整校验并分别报告，不新增比例门槛。
- 原模型、固定输入/trace、公开调用、九修改阶段、八计时阶段、完整校验、V1 和独立拥有输出语义保持。`read_sum=query_before+query_after`，`total` 为八阶段之和。冻结、共享 lease、容量复用和直接接收专项成绩不能替代原 owning 输出。
- 阶段展示可使用 `not_started / running / passed / rejected / blocked / closed`；机器台账的调度 `status` 与回执 `gate_outcome` 以 PLAN 末段映射为准，不强迫展示词与调度词相同，也不把 running 当通过。`blocked` 只表示具体必需输入、环境或外部条件缺失；候选收益不足用 `rejected`，不把整个开发标成停止。
- Cursor、allocation witness、CheckedRange、内部对齐、cell v1、bitmap transition/scoped-specialized 等旧实验不重开、不补样、不改名复活，不混合旧新样本，不回收取消候选的统计预算。

### 启动前预算与证据规则

1. 每个实际角色有自己的完整进程 `maxC/maxP` 来源，指标为 `finish_monotonic-start_monotonic`；不是native.total。令六角色之和为 `S=Σ(maxC+maxP)`，Q/F的事前筛查分别为 `388×S+300≤2700`、`772×S+300≤5400`；固定 `H_Q=H_F=300秒`，不得开窗后调整。两C14槽同SHA时，`S=2×(C14maxC+C14maxP)+Σ四竞品(maxC+maxP)`。旧X角色不能替代当前C14；历史max不是未来耗时保证。
2. 依据实际capture逐库投影logical wire、apparent bytes、unique allocated bytes、metadata及峰值slot，绑定输出卷/backing和审计路径；不能用均值、无依据去重或删除历史证据腾空间。新产物先完整语义通过，再允许byte-exact去重。不同合法padding保留真实字节和空间。
3. 资格和正式窗口使用同一登记策略，验证子会话是原共享租约内唯一实际重负载执行者，根统筹只授权/调度和验收。恢复工具须覆盖prelude、交接、命令deadline及恢复余量；不能只延长一层watchdog。实际用户应用是否存在/是否需要控制，以当前主机和授权为准，不照搬旧PID、CPU2或旧盘符。用户进程先恢复，再做离线审计。
4. Q2700、F5400、各audit3600均为独立新执行身份和有限预算，不是沿用旧结果的许可。一次窗口超时或失败保留前缀并关闭；资源不足在启动前解决，不能临时缩小样本或改统计单位。
5. 旧报告、hash及完整审计通过仅表示其历史作用域；未迁移原件不能算新机重审。正式候选/profile/fixture/宿主控制条件改变时重新评估资格绑定，不把已经通过的A/A视为永久通行证。

## 阶段终止与持续推进

任何阶段均先区分“实现缺陷”“证据缺失”“资源/工具失败”“统计未建立”四类原因。修复具体缺陷而不盲重试；安全反例、已消费窗口和不确定区间不能靠重命名消除。S0—S4可由不同子会话/agent并行交付设计、代码和审查；根统筹只授权、调度和验收，验证子会话通过原全局共享租约串行执行全部构建/SAN/业务/native和计时。S3/S5采样期间其他子会话/agent静默。

每次阶段完成仅报告实际产物、判据与下一动作。没有晋升候选不阻断继续设计；A/A失败只阻断对应正式比较；所有候选关闭也不能写成目标达成。只有当前闭包、完整门禁和正式四竞品目标均有相应证据时，才能宣布本轮性能目标完成。
