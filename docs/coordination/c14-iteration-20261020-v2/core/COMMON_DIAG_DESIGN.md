## Counts and first owning output

The canonical wrapper increments one call counter, retains exactly one original acquire load, and counts the result inactive/active. The owns helper increments a fixed thread-local scope depth/node counter; the existing const XFixedVector::data counts actual calls while within that scope. Owning vectors, capacity hits, nontrivial misses and nonempty misses are counted at their actual branches. Mutation-group scope stores cumulative snapshots on exit (including the old continue path), so all nine original public groups remain unmodified. Primary t0..t8 snapshots bracket the same original eight calls. Counts are perturbed logical observations, not CPU share or elapsed-benefit measurements.

save_verified preserves normalization, header creation, the original fresh std::string, bounds check, resize_and_overwrite callback, complete header/payload memcpy and return. Emit-internal hooks only update fixed POD/TLS and sample CLOCK_MONOTONIC/getrusage. They never format, allocate, log, reserve an output, pre-touch output pages, create another owning result or copy payload for observation. Sample flags record both syscall return values. The final consumer must require exactly one primary emit invocation, seen bits0..8, every clock/rusage status zero, nonzero monotone clocks and valid cumulative rusage. A bad clock is invalid evidence rather than zero time.

Emit indices are cumulative/nested: entry through normalization/root/allocator, header ready, string/checks ready before resize_and_overwrite, callback entry after string preparation, header copy done, payload copy done, resize returned, save return. String preparation includes allocator/library/observer work and is not pure malloc. Faults during preparation/copy already belong to those intervals; they cannot be added again. Mark8 is inside the callee immediately before return and does not replace the external t4 boundary.

The unique C14 process must execute original `run` first, with no validate/export/emit warmup before t0. Original query answers and final canonical/wire/query post-audit remain. A complete nine-stage audit belongs after the primary run; the validation-owned final driver may perform a replay there, inside the same registered child, provided its command/deadline/resource closure includes that work. It must never move stage exports into primary mutate. R1 must use the same final driver and audit. Proposed exact compile/native commands and fixed inputs are in REQUESTS_PHASE_C_DRAFT.json.
