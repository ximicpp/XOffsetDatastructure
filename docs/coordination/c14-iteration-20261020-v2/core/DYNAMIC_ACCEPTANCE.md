# Common diagnostic bridge and dynamic predicates

This is a source/count acceptance supplement, independent of the final C execution freeze. It does not change any accepted producer, wrapper, candidate, request or runtime input and must not delay final C registration. `DYNAMIC_ACCEPTANCE_BRIDGE.json` records the actual source checks. The offline helper `tools/c14_iteration_20261020_v2/core/check_dynamic_acceptance.py` consumes externally SHA-pinned, already successfully audited role `AUDIT.json` files; it cannot run a child. It reports count evidence only, with execution/codegen admission explicitly unchecked and speed/screen/QF false.

## Prerequisites before any count interpretation

The validation-owned final audit must first pass every external identity, event order/causality, syscall/sample status, exact36 records, one wait4 reaper, exit/deadline/RSS/body/allocation/cleanup, native final-wire/canonical/query and nine-stage truth condition. All primary emit masks/statuses and channel errors must pass. A failed/incomplete role is `invalid_evidence_close`, even if its available count prefix looks favorable. Close the affected diagnostic according to its registered stop policy; preserve evidence and execute no unregistered replacement, supplement or retry. Missing/changed shared-control closure leaves M2 unadmitted.

The checker assumes those externally pinned audits are authoritative; an embedded `status=passed` alone is not independent proof. Its standalone output never grants an engineering gate or timing admission. The original native rows, emission intervals, event failures and truth evidence remain available for the final audit.

## Snapshot algebra

Fields are uint64 integers, excluding booleans: canonical, inactive, active, owns, vectors, capacity_hits, nontrivial_misses, nonempty_misses, vector_data_reads. Every cumulative snapshot and derived increment must satisfy canonical=inactive+active, capacity_hits<=vectors, nontrivial_misses<=vectors-capacity_hits, and nonempty_misses<=nontrivial_misses, with no counter reversal or overflow.

Let P[0..8] be primary t0..t8 cumulative snapshots; require P0=0 and P8=counts. Eight phase increments are P[i+1]-P[i]. read_sum is the **sum of query_before/query_after increments**, never the interval between them.

Let M[0..9] be mutation scope exits; mutation_seen must equal1022, M0=0. Stage1 is **M1-P2**, stages2..9 are Mi-M(i-1). M1 already contains earlier load/query work; subtracting M0 would misattribute it. Require M9=P3 and sum(stage1..9)=P3-P2 for every field. Post-t8 replay has observation disabled and must not enter these snapshots. All eight phases, nine stages, read_sum and primary total are emitted separately by the helper.

## R1 predicate

For every phase, every mutation stage, read_sum and primary total, require C14 and R1 equality of all nine logical counters. The candidate still performs each original acquire and must classify the same calls. Then require read_sum.inactive>0. Positive inactive elsewhere alone does not establish a hit in the registered read_sum target.

Passing establishes that actual registered read_sum work reached the inactive-return path to which the independently reviewed bare R1 codegen change applies. It does not dynamically measure saved wrapper calls, instruction count, CPU share or elapsed savings. All-zero read_sum inactive closes as `closed_no_dynamic_hit`; changed work or failed truth/events closes as invalid. Report active/inactive counts without an invented frequency threshold.

## M2 predicate for this closed driver/source

At every scope above, require equal owns, vectors, capacity_hits, nontrivial_misses and nonempty_misses. Canonical counters and vector_data_reads may fall because those are the removed work. The original branch/recursive traversal and truth checks remain mandatory.

For each scope define N=nontrivial_misses, E=nonempty_misses, D=C14.vector_data_reads-M2.vector_data_reads, K=D-2*N, and C=C14.canonical-M2.canonical. Require **E<=K<=N and C=3*K**, plus nonincreasing inactive and active classifications. Why: original const range-for adds begin(data) and end(data?data+size:null) after the unchanged containment data; a null miss removes two data calls and zero canonical calls, a nonnull miss removes three data calls and three canonical calls. Thus K is the number of nonnull misses, with every valid nonempty miss included. Empty allocated vectors may also contribute, so K need not equal E. This equation is specific to the frozen actual driver/type and source closure, not a claim that arbitrary ADL recursion is callback-free.

Require primary mutate.E>0, primary mutate.D>0 and primary mutate.C>0. Stage increments must conserve the same total reductions and expose where they occur; no demand that every stage have eligible work. Failure of an equation is invalid evidence, not permission to relax it after seeing results. A valid window without the positive target hit closes `closed_no_dynamic_hit`. The actual bare4-to-1 codegen review remains a separate mandatory gate; diagnostic counter increments perturb optimization and cannot substitute for bare codegen or establish speed.

## Offline use and scope

After root validates final external closures, invoke the helper with `--candidate r1|m2 --control-audit PATH --control-sha256 SHA --candidate-audit PATH --candidate-sha256 SHA`. Stdout is a JSON predicate report; exit0 means mechanism_hit, exit2 means closed_no_dynamic_hit, exit1 means invalid_evidence_close. No result file is overwritten and no input is modified. The caller separately binds this helper identity and the actual audit identities.

Metadata-only synthetic checks covered R1 hit/no-hit, M2 hit, the stage1 baseline, wrong final stage boundary, producer errors, wrong data/canonical equation, changed R1 work and boolean counts. No actual diagnostic result, C++ compilation, native process or timing sample was used to prepare or check these predicates. First-output samples remain nested diagnostic intervals; they are not summed as independent costs or interpreted as pure malloc, speed or an explanation of the closed M1 timeout.
