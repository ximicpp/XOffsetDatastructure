# XOffset Mac 接续：结案报告（2026-10-20）

## 1. 结论

- 默认实现已由 C14 换为 **W9a**（分支 `claude/w9a-default-20261020`，提交 `14b57637…`），依据是用户的 D5 决定：Mac 正式验收与 Mac 门禁通过即替换。
- W9a 在本机 Mac 正式验收中通过 **7/12** 项主目标；剩余 5 项在现有语义下没有可证明的实现路径，附测量证据（§4）。
- 结论只适用于：Apple M4 mac mini、macOS 26.3、本机构建的 clang-p2996 `d77eff1` 工具链、恢复包中的 alpha 时期对比工具元数据（与 final-v4 相比 67 个文件中 9 个不同，含 `driver.cpp` 与 cista 适配器，对 cista 的两项比值影响最大）。与旧 WSL 上 F64 的 3/12 条件不同，不能直接比较。

## 2. W9a 是什么

W9a = R1+M2 + G1 + G + MV，并降级接收数据的指针来源承诺：

| 部分 | 内容 | 语义影响 |
| --- | --- | --- |
| 解析 | 所有内部指针解析一律 `字段地址 + 偏移`，不再做 canonical 检查 | 接收数据与普通加载同为已披露的平坦地址模型（README、`docs/ALPHA_COMPATIBILITY.md` 已改）；公开 `canonical_bytes_at` 与登记接口保留但库内不再使用 |
| G1 | 扩容只清零曾经暴露过的字节，操作系统新给的零页不再重复清零；接收存储仍全清零 | 读出字节不变 |
| G | 扩容探测不再靠抛异常 | 少一个 `new_handler` 回调点和一种 `bad_alloc`（用户已接受） |
| MV | 叶子类型移动赋值内联 owns / set_rel32 / release，同一分配器时复用 binding | 无 |

S/M/L 三档写出的 wire、模型真值、查询结果与 R1+M2 逐字节相同，互相读取正确（B7）。

## 4. 正式验收（W9-formal-mac-v1；W9a 机器码与 W9 相同）

联合单侧 95% 上界：

| 竞品 | 读取（≤1.05） | 修改（≤1.05） | 独立输出（≤0.20） |
| --- | ---: | ---: | ---: |
| cista | 0.954 ✓ | 1.011 ✓ | 0.214 ✗ |
| FlatBuffers | 0.759 ✓ | 0.883 ✓ | 0.2004 ✗ |
| Cap'n Proto | 0.268 ✓ | 0.357 ✓ | 0.563 ✗ |
| cereal | 1.040 ✓ | 1.464 ✗ | 0.278 ✗ |

同批相对 C14：读取 0.758、修改 0.337、独立输出 0.957、重载 0.929、总时间 0.639。重载（只报告）：cista 0.851、FlatBuffers 1.883、Cap'n Proto 1.424、cereal 1.534。

未达各项的证据：
- **独立输出 4 项**：输出 1.067 ms 中复制占 1.050 ms，其余约 9 µs（B2）。新进程里分配新 `std::string` 并复制 17.22 MB 的下限是 0.97–1.02 ms，W9a 只高约 5%（B3）。只复制格式必需的 15.05 MB 也要 0.835 ms，高于 Cap'n Proto（0.37 ms）与 cereal（0.79 ms）的要求。完全落在空闲块里的 16 KiB 页为 0；换分配策略省不下字节（B5）。写时复制已由用户裁定不算独立输出。对 FlatBuffers 的 0.2004 只超线 0.0004，W7 同代码批次为 0.196，属批次波动，按冻结规则记为未通过。
- **修改对 cereal**：差距分散在第 2–8 阶段，最大的是删除记录（+0.52 ms），空闲链表遍历远低于 3%（B1/B4）。没有可证明安全的机制。

## 5. 过程中的主要决定与否定结果

- 指针来源：先采用固定地址窗口（W2→W8，含安全证明与审查修正），后由用户改为降级（W9）。窗口方案的完整材料保留在备份分支。
- 预注册筛选（72 对 AB/BA）：G1、W2、G、MV 通过；T（加载否决）、O+R / N / E（效应太小）未通过；W5、W6 组合因加载被否决，W7 通过；W9 通过。
- 否定的方向：relaxed 原子读、普通全局变量或运行时变量做守卫、`__builtin_expect`、P / NZ（变慢）、RL / PF（无效）、空闲页留零页、分配策略缩小输出（C4）、输出固定开销削减（C1）、空闲链表按类跳过（C2）。
