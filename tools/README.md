# XOffsetDatastructure Tools

## Signature Export Tool (`export_signatures`)

Exports type signatures for key data types (Player, Item, GameData) to portable `.sig.hpp` header files.

### Requirements
- **Compile**: P2996 Clang (same as main project)
- **Run**: Any platform (generates platform-specific signatures)
- **Compare**: Any C++26 compiler (`.sig.hpp` files are pure constexpr data)

### Usage

```bash
# Build (via CMake, included in main build)
cd build
cmake --build . --target export_signatures

# Export to stdout
./bin/export_signatures

# Export to directory (creates <platform>.sig.hpp)
./bin/export_signatures tools/sigs/
```

### Output

The tool generates a `.sig.hpp` file containing:
- Platform metadata (arch, pointer size, endianness)
- Layout signatures (for byte-layout comparison)
- Definition signatures (for full type identity)
- Type registry for `CompatReporter`

### Example

```
$ ./bin/export_signatures tools/sigs/
Exported 3 type(s) to tools/sigs/x86_64_linux_clang.sig.hpp [x86_64_linux_clang]
```

## Cross-Platform Compatibility Check (`check_compat`)

Compares exported `.sig.hpp` signature files to verify binary layout compatibility across platforms. Uses compile-time `static_assert` for self-verification and generates a runtime compatibility report.

### Requirements
- **Compile**: Any C++26 compiler (P2996 is **NOT** required)
- **Input**: At least one `.sig.hpp` file in `tools/sigs/` (generated by `export_signatures`)

### Usage

```bash
# Build (via CMake, included in main build)
cd build
cmake --build . --target check_compat

# Run compatibility report
./bin/check_compat
```

### How It Works

1. **Compile-time self-verification**: `static_assert` confirms that each type's Layout and Definition signatures match themselves (sanity check).
2. **Runtime 3-layer report**: Prints a per-type compatibility report covering:
   - **Layout layer** — byte-level binary identity (includes internal bit-fields)
   - **Definition layer** — semantic type identity (uses Opaque container signatures)
   - **Safety assessment** — overall compatibility grade

### Adding More Platforms

To compare signatures across platforms:

1. Export signatures on Platform A: `./bin/export_signatures tools/sigs/`
2. Copy the generated `.sig.hpp` file to the build machine
3. Add `#include "sigs/<platform>.sig.hpp"` to `check_compat.cpp`
4. Add cross-platform comparison entries (e.g., `TYPELAYOUT_CHECK_COMPAT_CROSS(platform_a, platform_b)`)

### Example Output

```
  Definition: MATCH ✓
  Safety:     COMPATIBLE

Type: Item
  Layout:     MATCH ✓
  Definition: MATCH ✓
  Safety:     COMPATIBLE

  Layout:     MATCH ✓
  Definition: MATCH ✓

```
