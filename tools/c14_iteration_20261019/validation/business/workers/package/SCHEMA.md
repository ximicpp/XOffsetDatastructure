# R6 explicit final-source package input v2

prepare-spec.py writes schema_version integer 1, kind
receive-completion-package-input. Fields inherited from the original package
workers are retained; EXECUTION.md is the actual entry/calling contract.

| field | requirement |
|---|---|
| source | explicit absolute B/final-vN/source; no search or fallback |
| source_identity | explicit materialization path plus integer bytes/SHA256 |
| candidate_identity | explicit C descendant metadata path plus file ID |
| production_files | actual matching fourteen root production file IDs |
| own_headers | exact existing eleven-name set, materialization order |
| full_gates.normal/sanitized | supplied passed source/production-specific inventory acceptance records with IDs |
| expected_full_tests | exact unique sorted common normal/SAN names |
| expected_full_test_count | integer actual count, at least 71; not fixed to 71 |
| required_tests | original receive/raw/core/custom-future names |
| source_tools | maintained package tools, install/config metadata, VERSION/CHANGELOG/compatibility file IDs |
| execution_tools | exact receipt members, each with integer bytes/SHA256 |
| execution_author_receipt | this prepared source bundle's receipt file ID |
| runtime_fixture_files | unchanged fourteen original runtime source/helper files |
| shared_tools | exact original common/command/lease helper IDs |
| outputs/queues | exact fresh standard/runtime/archive v2 names in EXECUTION.md |
| queue_timeouts | package2400, runtime2400, archive3600 |
| full_dependency_scope | default9 and separate11 first-include objects/profile, zero probe native executions |

Workers independently bind spec source, materialization, candidate, passed full
inventories and all production/tool/fixture bytes before and after operation.
The unchanged maintained tools preserve storage C++17, full dependency lock,
851 third-party headers, exact installation members, relocation/source hiding,
3+3 consumers, alpha version-policy rejection and shared-runtime DSO consumers.

Archive output keeps original tar/ZIP, manifest, checksums, full results and
clean receive consumer. Each full result adds dependency_scope: nine required
default own headers and observed/not-observed own headers from actual VALID
Ninja sections. Independently, public_first_include_objects has normal and
sanitized records, each exact eleven compile-only first-include objects with
source/object IDs, compile rows and dependency report ID. There is no implication
that optional headers appeared in the default full tests.

No source preparation is an actual platform, compiler, native or package pass.
No v3 successful record becomes a pass for changed v4 production source.
