# Agent instructions

- Superpowers skills are opt-in for the current user turn only. Do not select,
  load, or apply them unless the current user explicitly invokes `@Superpowers`,
  `$superpowers:<skill>`, or asks to use Superpowers.
- Preserve historical evidence and immutable archives. Use new directories for
  builds and experiments; do not reset existing user changes to match a manifest.
- A successful handoff integrity check is not a platform test result.
